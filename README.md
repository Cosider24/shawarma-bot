# Бот-магазин «Шаурма на углу» (Telegram)

Учебный проект. Все товары, цены и контакты вымышленные.

## 1. Идея и роли

**Кто покупатель и что он хочет?** Человек, которому нужна шаурма быстро и без звонков: выбрать блюда в Telegram и забрать заказ.

**Что выбирает покупатель и какие сведения нужны?** Позиции из каталога (6 штук) и их количество. Для заказа нужны имя или псевдоним и способ получения (самовывоз / поесть на месте). Расчёт всегда «при получении».

**Что происходит после подтверждения?** Заказ сохраняется в базе с номером и статусом «Новый». Менеджер получает уведомление, видит заказ в списке «Новые заказы» и меняет статус (Готовится → Готов к выдаче → Выдан / Отменён). Покупатель получает сообщение о смене статуса и видит его в «Моих заказах».

**Когда заказ считается оформленным?** В момент нажатия «Подтвердить заказ»: заказ и его состав записаны в базу, корзина очищена. Бот нигде не пишет «Оплачено».

## 2. Путь клиента

```
/start → Каталог → Карточка позиции → Добавить в корзину
                         ↘ Корзина → (+ / − / удалить) → Оформить
                              → имя → способ получения → проверка итога → Подтвердить
                              → номер заказа → Мои заказы
Менеджер → Новые заказы → выбор заказа → смена статуса
```

## 3. Технологии

Python 3.10+, aiogram 3 (Telegram Bot API, long polling), SQLite (файл `shop.db`), python-dotenv.

## 4. Структура данных (SQLite)

- `users` — Telegram ID, платформа, имя
- `products` — название, описание, цена, доступность
- `cart_items` — пользователь, товар, количество (у каждого пользователя своя корзина)
- `orders` — покупатель, имя, способ получения, расчёт, итог, статус, дата
- `order_items` — заказ, название и цена **на момент покупки**, количество

Сумма считается в `db.py` по ценам из базы. Оформление заказа (создание заказа, состава и очистка корзины) выполняется одной транзакцией. Повторное «Подтвердить» не создаёт дубль: корзина уже пуста, а состояние оформления сброшено.

## 5. Запуск на чистом компьютере (Windows)

1. Установите Python 3.10+ (python.org, при установке отметьте «Add Python to PATH»).
2. Откройте терминал в папке проекта и выполните:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   copy .env.example .env
   ```
3. Создайте бота у @BotFather (`/newbot`), токен впишите в `.env`: `BOT_TOKEN=...`
4. Запустите: `python bot.py`. При первом запуске создаются таблицы и 6 стартовых товаров (в `db.py`, список `SEED_PRODUCTS`).
5. Откройте бота в Telegram и отправьте `/start`.

## 6. Как войти как менеджер

1. Отправьте боту команду `/id`, он покажет ваш Telegram ID.
2. Впишите его в `.env`: `MANAGER_IDS=123456789` (несколько ID через запятую).
3. Перезапустите бота. В меню появится кнопка «Новые заказы (менеджер)».

Менеджер определяется только по ID из `.env`, а не по тексту сообщения.

## 7. Ограничения

Только Telegram. Онлайн-оплаты нет (только «при получении»). Менеджеры задаются через `.env`, интерфейса редактирования каталога нет (товары меняются в базе). Состояние оформления хранится в памяти: если перезапустить бота посреди оформления, его нужно начать заново. Данные заказов и корзин остаются в базе.
